# Самостоятельный аддон загрузки входных данных GT

Весь рабочий код находится в `fetcher.py`. Папку `gt_addon` можно копировать
отдельно от GT. Аддон не импортирует `gtsimulation`, не запускает симуляции,
не меняет классы, коэффициенты, системы координат или файлы установленного GT.
Скачанные файлы сохраняются в явно указанный пользователем каталог.

## Что делает

- NASA OMNI2: почасовые входы T89 (категория Kp) и T96 (Pdyn, Dst, By/Bz GSM).
- Официальные TA15: пятиминутные входы T15B, By/Bz GSW и B-index;
  флаги интерполяции источника сохраняются. Без явного разрешения флаг 2 запрещён.
- CelesTrak: наблюдённые F10.7/Ap для NRLMSIS. История индексов готовится
  библиотекой pymsis в отдельном процессе; её настройки в родительском процессе
  не меняются. Сохраняются исходный CSV и выбранные дни с необходимой историей.

Пакет результата: исходные ответы, числовой `inputs.npy` и `manifest.json`
с UTC-интервалом, единицами, источником, датой получения и SHA256. Каждый вызов
создаёт новый каталог. Пропуски не интерполируются и не заменяются другими данными.
NPY читается с `allow_pickle=False`. Неполный пакет после обработанной ошибки удаляется.

## Установка и использование в Windows

Из корня этой копии репозитория (Python 3.10 или новее):

```bat
python -m venv gt_addon\.venv
gt_addon\.venv\Scripts\python.exe -m pip install ./gt_addon pytest
```

Если окружение уже подготовлено, повторно создавать его не нужно.
Пример загрузки T96:

```bat
gt_addon\.venv\Scripts\python.exe gt_addon\fetcher.py --model 96 --start 2024-09-10 --end 2024-09-11 --output-dir gt_addon\inputs
```

Выбор `--model`: `89`, `96`, `15B`, `nrlmsis`.
Для T89/T96/NRLMSIS границы должны быть целыми часами UTC, для T15B — кратны
пяти минутам. Интервал `[start, end)`: начало включено, конец исключён; до 366 дней.
Зональные ISO-даты переводятся в UTC, даты без зоны считаются UTC.
Параметр `--allow-provider-interpolation` допустим только для T15B.
После установки доступна также команда `gt-fetch`.

Python API установленного пакета:

```python
from fetcher import download_tsyganenko_inputs
result = download_tsyganenko_inputs(
    "2024-09-10", "2024-09-11", "my_inputs", model="96"
)
print(result["input_file"], result["manifest"])
```

Другие функции: `download_ta15_inputs` и `download_atmosphere_inputs`.
Аддон выдаёт файлы, но не добавляет GT параметр `input_file` и не подключает
результаты к модели автоматически. Применение файлов в научном расчёте
контролирует пользователь/разработчик GT. Параметры моделей GT здесь не изменены.

## Проверка

Детерминированные тесты (интернет не нужен):

```bat
set PYTEST_DISABLE_PLUGIN_AUTOLOAD=1
gt_addon\.venv\Scripts\python.exe -m pytest gt_addon\tests -q -W error
```

Ожидается 106 passed. Проверяются форматы, значения, UTC, пропуски, безопасность
NPY, повторные попытки, 404/503/таймауты, ошибки записи, сохранность прежнего
пакета, восстановление после отказа, отсутствие импорта GT и работа CLI.
Тесты физических моделей исключены: аддон их не исполняет.

Реальная загрузка четырёх моделей и независимый пересчёт чисел из исходников:

```bat
gt_addon\.venv\Scripts\python.exe gt_addon\tests\check_live.py
```

Результаты сохраняются в `gt_addon/results/live-.../report.json`.
Ошибка внешнего сайта отмечается FAIL, а не считается успешной загрузкой.
Можно повторить только один источник: добавьте `--models nrlmsis`.
Для честного повторного прогона сохранённых ответов используйте
`--replay-dir "путь/к/каталогу/с/исходными/пакетами"`. Скрипт сверяет их
старые SHA256, явно выводит режим offline replay и не выдаёт его за новую загрузку.
Ветка теста T15B явно разрешает интерполяцию источника и сохраняет её флаги.
Проверка не импортирует GT и не вызывает его физические модели.

## Научные границы

Системы координат источника не преобразуются: T96 By/Bz — GSM, T15B — GSW.
Загрузчик не сертифицирует согласованность координат последующего расчёта GT.
Kp имеет исходный шаг три часа; почасовая таблица не делает его почасовым
измерением. Атмосферные F10.7/F10.7a/Ap — суточные, ap — трёхчасовой;
почасовое сохранение не повышает исходное разрешение.

Для T15B соблюдается существующий предел B-index 0..2, для атмосферных входов
прогнозные/неполные записи отклоняются. Новые драйверы не расширяют срок
действия коэффициентов физических моделей. Доступность всех дат не гарантируется.
Проверка сертификатов TLS не отключается; при ошибке сертификата загрузка
завершается отказом. Сервис TA15 может отдавать неполную цепочку сертификатов,
поэтому доступность зависит также от доверенного хранилища среды.

## Состав и история

`fetcher.py` — реализация; `tests/` — проверки; `pyproject.toml` и requirements —
установка; этот README — инструкция. Скачанные данные, окружение и временные
результаты исключены из Git. Рабочие классы GT восстановлены по исходному
коммиту `095dc71b0561cbe19a7ee436f65eda62fc2baff3`.

Прежние научные аудиты, сторонний компилятор, результаты симуляций и журналы
не входят в текущую поставку. Они сохранены отдельно локально и в истории Git.
