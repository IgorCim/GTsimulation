# Input inventory and scope of the GT addon

Audited against GT base 095dc71b0561cbe19a7ee436f65eda62fc2baff3.
The addon prepares external inputs; it does not replace GT's scientific models.

| Consumer | Input | Handling |
|---|---|---|
| Tsyganenko 89 | Kp activity bin | NASA hourly OMNI2 download; Kp retains its original three-hour meaning |
| Tsyganenko 96 | Pdyn, Dst, IMF By/Bz GSM | NASA OMNI2 download, explicit UTC interval and invalid-value rejection |
| Tsyganenko 15B | Pdyn, IMF By/Bz GSW, B-index | Official TA15 annual files; five-minute slots, quality flags, no gap filling |
| GTnrlmsis | Previous-day F10.7, centred 81-day F10.7, Ap history | CelesTrak download, preparation with installed pymsis, numeric offline bundle |
| Geant4 atmosphere helpers | Same F10.7/Ap data | Prepared CSV can be explicitly selected with public pymsis API; Geant4 execution not tested here |
| Gauss Earth/planet/moon models | Version-specific coefficient arrays | Already shipped in GT package; installing GT supplies these inputs |
| Earth reference transformations | IGRF14 coefficients | Already shipped; model date validity still applies |
| Date-dependent dipole | HarmonicCoeffsIGRF.npy | Already shipped; existing date limits remain |
| Particle species / GCR spectrum | NuDat and Boschini2020 tables | Already shipped in particle/data |
| JF12 turbulence | Large random realisation MAT file | Generated by existing galaxy/Scripts/generate_jf12_turbulence.py, not an external observation download |
| IRI2016 | IRI auxiliary data | Import is disabled in medium/magnetosphere/__init__.py and iri2016 is not a declared dependency; enabling this unfinished model is outside the downloader |
| Particle start conditions | Energy, location, direction, species, number | User configuration, not downloadable environmental observations |
| Geant4 libraries/data | Software dependency datasets | Managed by Geant4 installation, not by the scientific input downloader |

## Important distinctions

Updating IGRF/CHAOS or other coefficient versions is not required to download
external drivers for models already in this GT release. It would be a separate
model-data migration with compatibility and scientific validity checks. The addon
does not silently overwrite coefficients, change fitted models or extend their
validity periods. These are distinct
from preparing external inputs for already supported models.

TA15 source values are in GSW; existing GT uses GSM positions and tilt with those
same drivers. The addon preserves that convention and warns when external T15B
inputs are selected. It does not claim to correct this approximation. The full
2023 source has been checked against all 96,104 corresponding bundled records,
including dates and values at the original float16 precision. New files retain
float64. B-index outside 0..2 is rejected by the addon because GT explicitly warns
that such values are outside its allowed range. Existing bundled behavior remains
unchanged.

Atmospheric preparation rejects non-observed rows, gaps and invalid inputs in the
requested days and required preceding history. It retains the provider's already
computed 81-day average, rather than inventing its own. Computation runs in a
separate process so it does not redirect pymsis for unrelated callers. The full
CSV and selected CSV are both retained. Prediction support is not claimed.

No downloader can guarantee data availability for every date or source outage.
A rejected interval is an explicit failure, not a successful simulation with
substituted data. Network availability is checked separately from deterministic
contract tests. Geant4, all platforms, and scientific accuracy of every GT model
are not covered by this addon test suite.
